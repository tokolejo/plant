# User Dashboard Route Group: `app/[locale]/(dashboard)`
This group handles authenticated user operations:
- `/dashboard` - Overview, stats, and quick actions
- `/dashboard/listings` - Manage active, hidden, and sold listings
- `/dashboard/listings/new` - Create listing (min 2, max 5 images, trade tags, delivery options, tier limits)
- `/dashboard/listings/[id]/edit` - Edit listing
- `/dashboard/messages` - Real-time buyer/seller conversations
- `/dashboard/profile` - Profile settings, bio, phone, badges, and reviews
- `/dashboard/affiliate` - Unique promo code stats and referral earnings
- `/dashboard/subscription` - Upgrade/manage subscription tier & billing cycle
