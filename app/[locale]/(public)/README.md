# Public Route Group: `app/[locale]/(public)`
This group handles all public-facing pages:
- `/` - Marketplace Home & Featured Listings
- `/listings` - Filterable Catalog & PostGIS Radius Geo-Search
- `/listings/[id]` - Listing Detail & Seller Contact
- `/iso` - "In Search Of" / Plant Trade Matchmaking Board
- `/shops/[slug]` - Custom Seller Storefront (Tier 2/3)
- `/pricing` - Subscription Plans & Tier Comparison
- `/auth/login` & `/auth/register` - Authentication screens
